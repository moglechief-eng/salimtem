개인정보처리방침 (Privacy Policy)

시행일: 2026년 11월 9일 · Effective: November 9, 2026

1. 이 도구에 대하여 / About this tool

Salimtem Publisher(이하 "도구")는 '살림꿀템' 채널 운영자 본인이 자신의 YouTube·Instagram·Threads 계정에 영상을 예약 게시하고, 자신의 게시물 성과를 확인하기 위해 사용하는 내부 도구입니다. 다른 사용자에게 제공되지 않습니다.

Salimtem Publisher (the "Tool") is an internal tool used only by the owner of the Salimtem channel to schedule uploads to their own YouTube, Instagram and Threads accounts and to view statistics for their own posts. It is not offered to any other user.

2. 사용하는 정보 / Data accessed

  • Google 계정 인증 정보(OAuth 토큰): 운영자 본인 채널에 동영상을 업로드하고 공개 설정을 관리하기 위해 사용합니다. YouTube API 범위: youtube.upload, youtube.readonly.
    Google OAuth tokens are used only to upload videos to and manage the owner's own channel (scopes: youtube.upload, youtube.readonly).
  • 운영자 채널의 동영상 통계(조회수 등): 운영자 본인의 성과 확인용입니다.
    View counts and similar statistics of the owner's own videos, for the owner's own reporting.

이 도구는 시청자나 다른 YouTube 사용자의 개인정보를 수집하지 않습니다. The Tool does not collect personal data of viewers or any other YouTube users.

3. 보관과 보호 / Storage and security

인증 토큰은 운영자의 비공개 저장소의 암호화된 비밀값(GitHub Secrets)에만 저장되며, 로그나 화면에 출력하지 않습니다. 정보는 제3자에게 판매·공유·이전하지 않습니다.

Tokens are stored only as encrypted secrets in the owner's private repository and are never printed to logs. No data is sold, shared or transferred to third parties.

4. Google 정책 준수 / Google API Services

이 도구가 Google API로부터 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다. 이 도구는 YouTube API 서비스를 사용하며, YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

The Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The Tool uses YouTube API Services; the YouTube Terms of Service and the Google Privacy Policy apply.

5. 접근 권한 철회와 삭제 / Revoking access and deletion

운영자는 언제든지 Google 계정 보안 설정에서 이 도구의 접근 권한을 철회할 수 있으며, 철회 시 저장된 토큰은 7일 이내에 삭제됩니다.

Access can be revoked at any time from Google Account permissions; stored tokens are deleted within 7 days of revocation.
